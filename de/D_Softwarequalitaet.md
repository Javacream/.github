## Fachlicher Schwerpunkt: Softwarequalität

Qualitätskriterien und Softwaremetriken, Clean Code, Refactoring, statische Codeanalyse sowie Softwaretesting und Testautomatisierung.

- **Qualitätskriterien und Metriken:** Qualitätsmodelle, Wartbarkeit, Komplexität, Code-Metriken und statische Codeanalyse
- **Clean Code und Refactoring:** Clean-Code-Prinzipien, Code Smells, Refactoring-Techniken und Code Reviews
- **Softwaretesting:** Teststrategien, Unit-Tests, Integrationstests, End-to-End-Tests, Testautomatisierung, TDD, JUnit und pytest
