## Fachlicher Schwerpunkt: Java

Konzeption und Entwicklung moderner Java-Anwendungen mit Schwerpunkt auf Spring und Spring Boot, objektorientierter Softwareentwicklung, Enterprise-Anwendungen, REST-Schnittstellen, Datenpersistenz und Integration verteilter Systeme.

- **Java und objektorientierte Programmierung:** Java SE, Sprachkonzepte, Collections, Generics, Streams, funktionale Programmierung und moderne Java-Versionen
- **Spring Framework und Spring Boot:** Dependency Injection, Spring Core, Spring Boot, Konfiguration und Anwendungsarchitektur
- **Web- und REST-Anwendungen:** Spring MVC, REST-APIs, Spring Web, OpenAPI und Swagger UI
- **Persistenz und Datenbanken:** JDBC, JPA, Hibernate, Spring Data JPA und Transaktionsmanagement
- **Integration und Messaging:** Spring Integration, Spring for Apache Kafka und ereignisgesteuerte Kommunikation
- **Testing und Qualitätssicherung:** JUnit, Mockito, Spring Boot Test, Integrations- und automatisierte Anwendungstests
